# 浏览器端到端与资源基准验收

> 本报告记录子树整体命中优化之前的基线，尤其全根查询耗时不代表当前实现。后续优化与对照见[对比总结](comparison-summary.md)。

2026-10-25 完成一次完整 Chrome 验收：70 项浏览器契约断言、108 组查询性能组合全部通过，
每组计时前与独立 JS 暴力扫描核对。MoonFlame 生成的 SVG 已在浏览器验证加载、缩放、搜索和复位。
这是一台桌面设备的实测，不代表 M2 整体验收或受限设备容量保证。

## 环境与复现

- AMD Ryzen 7 8845HS，16 逻辑 CPU，系统内存 24,429,539,328 字节。
- Linux 7.2.11-200.fc44.x86_64；Chrome 156.0.8078.47（headless），V8 15.6.75.19；Node 22.23.1。
- moon 0.1.20261020，moonc v0.10.16+b1a0e846e。延迟测 release stripped，分析另用 release `--no-strip`。
- 测量时间为北京时间 18:16–18:18；采样分析在延迟测量之后独立执行。
- 核心基线提交 `c293782`；基准源码当时尚未提交，其 SHA-256 与模块 SHA-256 均写入原始记录。

[原始记录](../benchmarks/results/2026-10-25T10-16-50-071Z-chrome-linux.json)包含所有延迟样本、
环境、正确性结果、资源快照和采样数量。[复现步骤与完整口径](../benchmarks/README.md)说明计时边界。
最终测量期间没有并行编译。种子为 `20261025`，三个规模（1 千、1 万、10 万），
三个分布（均匀、双簇、全重叠），三个查询负载，四个后端。

每次公开批量查询包含 8 条查询，每条容量 64；20 次预热、100 次采样，后端轮换顺序。
下表单位是 **毫秒/批**，包含传输与结果复制；不能除以 8 当作单条查询的尾延迟。

## 构建与体积

10 万对象，5 个独立实例的构建 p50（毫秒，实例化不计入）：

| 分布 | wasm 块传输 | wasm 标量 | wasm-gc 标量 |
| --- | ---: | ---: | ---: |
| 均匀 | 59.780 | 83.920 | 73.305 |
| 双簇 | 58.260 | 81.295 | 52.910 |
| 全重叠 | 29.105 | 54.640 | 46.705 |

均匀构建块传输相比 wasm 标量减少约 28.8% 耗时；查询收益则随负载变化。
构建仅 5 次采样，不据此承诺稳定尾延迟。JS 扫描的初始化只复制数组，不与索引构建等同。

| 发布模块 | 原始字节 | gzip level 9 字节 |
| --- | ---: | ---: |
| wasm 块传输 | 29,056 | 13,915 |
| wasm 标量 | 26,416 | 12,557 |
| wasm-gc 标量 | 21,035 | 8,815 |

体积不含 JS 包装器与页面。保留名称的分析模块为 78,396 字节，单独用于采样。
本地 HTTP 首次可查询单次观测分别为 7.325 / 6.300 / 4.770 毫秒（1 千均匀对象）；
受缓存、启动顺序和 JIT 影响，不代表公网加载或严格冷启动。

## 资源与火焰图

单独创建 10 万均匀对象的 wasm 块传输实例：初始线性容量 65,536 字节，构建后为
45,088,768 字节（43 MiB），100 批查询后相同。宿主输入数组为 5,200,032 字节，结果 ID 数组为 2,048 字节。
释放前线性容量仍为 43 MiB；丢弃引用并强制 GC 后，CDP backingStorageSize 回到基线的 106,276 字节。
这些是分阶段快照和已分配容量，**不是整个浏览器进程 RSS 或活跃堆峰值**，各字段不能盲目相加。

用户指定的 [gywcs101/moonflame@0.2.0](https://mooncakes.io/docs/gywcs101/moonflame@0.2.0)
负责折叠调用栈到交互 SVG 的渲染。Chrome CDP 负责采样；MoonFlame 放在独立模块编译为 JS，
不加入 octree 核心依赖、不进入被测路径。每个样本权重为 1，保留 GC/idle 等帧，不能当作精确函数计时。

- 反复重建：1,444 个样本，`split` 自身约 37.3%，构建内部函数约 15.7%，`moonbit.gc.free` 约 14.4%。
- 射线查询：1,413 个样本，`run__query` 自身约 97.5%。
- 全根查询：1,477 个样本，`run__query` 自身约 76.5%，`Aabb.intersects` 自身约 22.2%。

这些比例提供优化线索；采样、内联及名称保留会影响归属，不能单凭火焰图断言具体源码行是瓶颈。
本地生成的 `.cpuprofile`、`.folded`、`.svg` 与截图位于 `_build/browser-results/`，按复现步骤可重建。
