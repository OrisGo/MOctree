# 接口契约

状态：第一阶段契约已由用户确认，并在静态 AABB 核心中落实。更新日期：2026-10-21。

## 1. 数据与构建

| 项目 | 已确认行为 |
|---|---|
| 精度 | 首版几何输入、存储和计算使用 Double |
| ID | 32 位无符号整数，允许 0 和最大值；一个索引内唯一 |
| 根 | 调用者显式提供中心和正半边长，构建后固定；不自动推导或扩根 |
| 空输入 | 合法；保留一个深度为 0 的根，对象数为 0 |
| 快照 | 构建复制条目集合；几何值没有可变公开字段，之后修改输入数组不影响索引 |
| 失败 | 整体成功或整体失败，不返回部分索引，不影响旧索引 |
| 重复 ID | BuildError::DuplicateId，包含输入位置和 ID |
| 根外对象 | BuildError::OutsideRoot，包含输入位置和 ID，不裁剪或丢弃 |
| 对象容量 | max_objects 必填且非负；超出报错，包含上限和实际数量 |
| 节点容量 | max_nodes 必填且至少为 1，包含根；耗尽时停止细分并扫描 |
| 错误优先级 | 报告一个明确错误，不承诺多个错误之间的固定优先级 |

Vec3 是原始坐标值；Aabb、Cube、Ray 由校验构造函数创建。非法几何在构造时返回 GeometryError，因此不能将其提交给构建或查询后伪装成空结果。

数量上限不是字节上限。数组容量、构建临时空间和运行时开销可能高于逻辑计数；宿主内存耗尽不承诺转换成业务错误。

## 2. 几何与分裂

- AABB 使用有限坐标和闭合边界，相切算相交；允许点、线、平面等零尺寸。
- 任一轴 min > max 报错，不交换边界；拒绝 NaN 与正负无穷。
- 根计算出的边界必须有限，且三个轴都有可表示的正宽度；半边长为正但加减后边界重合仍报错。
- 不引入全局 epsilon 或隐式扩大查询盒。需要容差时由应用显式扩大查询范围。
- 坐标计算采用 Double 浮点语义，不宣称任意实数上的精确算术；采用避免中点和射线差值溢出的计算形式，并以边界和极端值测试验证。暴力对照使用同一公开几何谓词，另有独立解析场景验证谓词。
- 每个对象只存一次。只有整个 AABB 能归入子盒时才下沉，跨分割面的对象留在父节点，查询会检查内部节点对象。
- 分割时每轴先判断 min >= mid 归正侧，再判断 max <= mid 归负侧，否则跨面。分割面上的零尺寸对象归正侧。
- 子区编号为 x 位 1、y 位 2、z 位 4；构建按 0 到 7 顺序处理。
- 默认 split_threshold 为 16，必须至少为 1；对象数大于阈值才尝试分裂。
- 默认 max_depth 为 16，可配置为 0–64，根深度为 0。
- 至少有一个对象能下沉才分裂；只创建实际非空孩子。
- 一次分裂需要的孩子若不能全部容纳于剩余节点预算，则整个节点不分裂。
- 单孩子链允许继续下降。达到深度上限，或任一轴中点不再严格处于两端之间时停止。
- 相同版本、输入顺序和配置生成可重复结构；不承诺跨版本保持结构一致。

归属规则不改变查询的闭合边界语义。根外的查询盒合法，可以跨根或完全位于根外。

## 3. 射线

位置定义为 `origin + t * direction`：

- 起点和方向分量必须有限，方向不能全为零。
- 允许零方向分量和负零，平行轴单独处理。
- 方向不要求归一化；仅单位方向下 t 表示距离。
- 调用者显式给出有限闭区间，满足 `0 <= t_min <= t_max`。
- 允许等端点区间；第一阶段不支持负参数或无穷端点。
- 返回相交 AABB 的 ID，每个 ID 至多一次，不返回网格精确命中，不保证距离排序。

合法无命中与非法输入不同：前者是完整空结果，后者在几何构造或查询参数检查时返回明确错误。

## 4. 查询输出与工作区

公开操作见 [API 使用说明](api.md)，名称与签名由生成的 `.mbti` 文件描述。

- 分配式查询返回新数组；结果顺序未指定，不保证按 ID、距离或输入顺序排序。
- `query_aabb_into` 和 `query_ray_candidates_into` 使用调用者提供的固定数组、offset 和可选 capacity。
- offset 默认 0，capacity 默认数组剩余长度。区间必须合法，检查避免整数加法溢出。
- 覆盖选定区间的前 written 项，不追加、不清零；未写入部分保持原值，调用者仅消费有效前缀。
- 容量不足仍继续查询，返回准确 total_hits、written 和 Complete/Truncated。
- `total_hits > written` 才是 Truncated；恰好填满但已写完全部命中是 Complete。
- 允许零容量，用于计数；不提供续查游标，扩容后可重新查询。
- Workspace 由调用者持有，索引不保存它，也不保存结果缓冲。
- `index.workspace()` 创建足够大的工作区。手工指定容量不足时查询前报错，不修改输出。
- 当前迭代 DFS 的工作区要求是 `1 + 7 × 实际最大深度` 个节点索引。这是保守上界，查询中不扩容。
- 同一工作区不能用于交错或重入的查询/遍历；使用不同工作区可避免临时状态冲突。本阶段不承诺多线程。

查询内部没有结果数组或遍历栈增长，但不承诺各后端完全零分配；查询状态值等成本留给第二阶段测量。

## 5. 遍历与统计

遍历采用深度优先、父节点先于孩子、孩子编号递增的顺序。回调返回 false 可停止。

NodeInfo 提供索引实例内的节点 ID、边界、深度、所属子区编号、直属对象数和孩子位掩码。根的子区编号为 -1。`node_object_id` 按偏移读取本节点对象 ID，不暴露可修改数组。非法节点或对象偏移报错。

节点 ID 只在所属实例中使用，不承诺跨重建、转换或未来动态更新保持稳定。回调可使用另一个工作区查询当前索引，不得复用正在遍历的工作区。

统计口径：

- 结构：对象数、实际节点数、实际最大深度、配置上限、分裂阈值。
- 容量：条目数组、节点数组、对象顺序数组的元素容量，以及工作区要求；不是运行时字节数。
- visited_nodes：从遍历栈取出并进行节点剪枝判断的节点数，包含被剪掉的节点。
- tested_objects：实际执行包围盒或射线相交判断的对象数。
- total_hits：所有几何命中数。
- written：实际写入所选输出区间的数量。

## 6. 批量接口：纯 MoonBit 已实现，宿主适配留给 M2

- 每条查询使用调用者指定且互不重叠的输出区间。
- 分别返回错误、数量和完整性；单条溢出不占用其他查询的容量。
- 单条非法查询不阻止其他合法查询。
- 批次整体偏移越界或输出区间重叠，在执行前报错。
- JS/WASM 的具体编码、导出名称和缓冲生命周期协议在 M2 落实，不把内部布局作为稳定 ABI。

2026-10-23：`query_aabb_batch_into` 和 `query_ray_candidates_batch_into` 接受
`ArrayView[BatchQuery[Aabb]]` / `ArrayView[BatchQuery[Ray]]`。每项携带
`Result[几何类型, GeometryError]` 及必填 offset、capacity，几何构造失败可捕获后作为 Err 传入。
返回新分配的 `Array[Result[QueryStats, GeometryError]]`，顺序、长度与请求一致；
Err 原样传回且不写其输出区间，Ok 的计数、统计和完整性与单条查询一致。

执行前检查所有请求的区间（包括 Err 请求），越界返回带请求位置的
`BatchError::InvalidOutputRange`；非空区间重叠返回带两项位置的
`OverlappingOutputRanges`。区间是半开区间，首尾相邻合法；零容量区间不占空间，
可位于其他区间内部或输出末尾。检查用减法避免 offset + capacity 溢出。
非空批次工作区不足返回 `BatchError::InsufficientWorkspace`，即使所有请求均为 Err；
空批次返回空数组，不要求工作区容量。上述批次错误均在任何输出写入前返回，
不承诺多种批次错误之间的固定优先级。

请求按输入顺序执行并复用同一工作区；不保留请求、输出或工作区。
结果数组归调用者所有。区间检查使用临时数组排序（O(B log B) 时间、O(B) 临时元素，
B 为批次数量），报告数组也占 O(B) 元素；不承诺批量接口零分配。

JS/WASM 已有 [实验原型协议](wasm-prototype.md)，用于验证双后端路径。
其 JS 返回独立结果副本，具体导出和数值状态仍为草案，不改变上述核心 API 契约。

## 7. 后续扩展

动态写入、实际单精度存储和点云索引是已确认目标，以下详细问题留到对应阶段：

- 动态对象：重复插入、删除未知 ID、更新失败原子性、容量失败、根外更新和遍历失效；先考虑固定根内更新与查询不交错。
- 单精度：输入/存储/计算精度组合、超范围处理、保守转换与跨精度查询；不得仅接收单精度输入而继续保存 Double。
- 点云：距离度量、半径端点、k 范围、等距结果、重复位置、排序和缓冲不足；不同 ID 的重复位置不得默认去重。
- 动态点云：点移动、删除、ID 生命周期和维护策略，不直接套用对象树内部实现。

loose 规则、自动扩根、数值泛型和 Morton 排序仍是候选技术。降采样不是默认索引行为。
