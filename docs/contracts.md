# 接口契约与待决事项

状态：方向已确认；下表中的待决事项须在对应功能实现前明确并写入测试。更新日期：2026-10-21。

## 1. 已确定的契约

| 方面 | 契约 |
|---|---|
| 首版数据 | 对象 ID + AABB 几何快照，暂用 Double |
| 更新 | 首版只读，通过显式重建更新；后续提供独立动态类型 |
| 身份 | 外部 ID 与节点编号及物理位置分离 |
| 归属 | 一个对象存一次，跨分割面对象可留在内部节点 |
| 查询 | 精确到定义的包围盒谓词，对真实模型仍为候选集合 |
| 根外对象 | 明确报错，不裁剪、不丢弃 |
| 节点预算 | 无法继续分裂时允许局部扫描，不以丢对象满足预算 |
| 结果容量 | 不足时明确报告结果不完整，不能把截断当完整 |
| 遍历 | 只读，不承诺节点编号跨重建或更新稳定 |
| 宿主边界 | 批量接口、明确复制与所有权，不把内部布局作为稳定 ABI |

这些约束不表示所有内存分配失败都能转为业务错误。容量限制与宿主运行时的内存耗尽必须分别说明。

## 2. 首版实现前必须决定

| 问题 | 需要明确的内容 |
|---|---|
| ID | 编码范围、是否要求唯一、重复 ID 的错误行为；建议索引内唯一以便后续动态更新 |
| 根来源 | 调用者提供，还是可从输入推导后固定；空输入和退化根如何处理 |
| 构建失败 | 非法条目、根外条目、对象容量超限是否整次失败；建议首版采用整体失败，避免隐式部分索引 |
| AABB 边界 | 相切是否相交、零尺寸是否合法、倒置边界如何报错 |
| 数值范围 | NaN、无穷、有限大数计算溢出及可表示范围 |
| 分割面 | 在多个闭合子盒中都可包含的零尺寸对象如何唯一归属 |
| 细分 | 分裂阈值、最大深度、节点预算、停止条件与确定性 |
| 数值退化 | 中点与端点重合时停止细分，如何避免无进展递归 |
| 射线 | 参数区间端点、是否允许负参数或无穷端点、零方向分量、零向量、是否要求归一化 |
| 查询输入错误 | 与“合法但零命中”使用不同状态 |
| 结果顺序 | 是否保证排序或稳定性；不应默认承诺跨布局一致 |
| 缓冲写入 | 覆盖或追加、有效写入区间、已有内容是否保留 |
| 容量不足 | 是否继续统计总命中数、是否提前停止、是否支持重试或续查 |
| 工作区不足 | 预先保证足够、显式报错还是允许扩容；不允许静默漏查 |
| 批量查询 | 每条结果的偏移、数量、完整性和错误；共享容量的分配规则 |
| 遍历信息 | 可观察的边界、深度、孩子和对象信息，以及顺序保证 |
| 所有权 | 构建输入是否复制，查询缓冲的借用与失效条件 |

“只有一个非空孩子”不自动等于细分无效，继续下降可能改善后续分布。停止规则应结合实际几何进展、预算和分裂策略确定。

结果缓冲恰好填满不等于结果被截断。实现必须区分“已经写完全部命中”和“仍存在无法写入的命中”，或使用明确的未确认完整状态，不能仅按写入数量推断完整性。

## 3. 统计口径

至少区分：

- 结构：对象数、实际节点数、实际最大深度、配置上限及可观测容量。
- 查询：访问节点数、测试对象数、几何命中数、实际写入数。
- 资源：构建临时空间、稳态索引、输入输出和传输副本。

如果查询提前停止，未遍历部分的命中总数应标为未知，不得将已写入数称为总命中数。各后端不可观测的内存应明确说明，不能用逻辑容量替代实际峰值。

## 4. 后续扩展的契约门槛

### 动态对象索引

实现前确定插入重复 ID、删除未知 ID、更新失败的原子性、容量耗尽、根外更新和遍历失效规则。建议首先采用固定根内更新与查询不交错的使用方式。

是否采用 loose octree、自动扩根、节点合并或定期重建，属于后续实现决策；动态写入本身是已确认目标。

### 单精度

明确输入、存储与计算精度；建立超范围处理、保守 AABB 转换和跨精度查询规则。分别验证原生单精度数据和从 Double 转换的数据，不混淆其正确性参照。

单精度版本需要实际降低坐标存储成本，并报告总内存和性能变化。

### 点云索引

点云采用独立的 ID + 三坐标存储。实现前确定距离度量、半径端点、k 的范围、等距结果、重复位置、结果排序及缓冲不足时的语义。

不同 ID 的重复位置不能默认被去重。降采样属于改变数据集的独立功能，不是空间索引的默认行为。

动态点云索引还需确定点移动、删除与 ID 生命周期，不直接套用对象 AABB 更新的全部实现细节。
