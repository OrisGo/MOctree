## 测试内容

- 几何合法性：NaN、无穷、倒置边界、零尺寸、无效根、正宽度因舍入消失。
- AABB 闭边界：面、边、角相切；根的外表面；分割面上的点归正侧。
- 射线：有限闭区间、等端点、非单位方向、负方向、平行轴、负零、原点在盒内、非法方向和区间。
- 数值：射线差值溢出但参数仍有限，大坐标同号边界中点，以及 `1e308`、`1e-300`、`5e-324` 尺度。
- 构建：空树、重复 ID、最大 UInt32 ID、根外条目、对象容量、节点预算整体停止分裂、深度 0/64、数值退化。
- 所有权：构建后修改并清空输入数组，不影响索引；相同输入生成一致结构。
- 输出：零容量、恰好装满、截断、准确计数、偏移区间、未写尾部、工作区不足、越界检查及缓冲复用。
- 遍历：前序、子区顺序、主动停止、内部节点对象、非法访问与统计口径。
- 白盒不变量：每个对象恰好归属一个节点、节点对象区间有效、父盒包含孩子及直属对象、孩子位掩码一致、每个非根节点恰有一个父节点、节点数不超过预算。
- 对照：8 种分布 × 3 档节点预算 × 96 组查询，每组比较 AABB 与射线查询及缓冲路径；每份数据 160 个条目。
- 独立射线对照：轴平行射线使用 Y/Z 范围比较直接求期望结果，不依赖 slab 除法。
- API 示例：使用根包导出的构造、查询与缓冲接口执行文档中的示例并断言结果。

八种分布为均匀、聚簇、平面、细长、全部重叠、重复位置、巨大跨节点混合对象、分割面上的点。随机生成器使用固定种子和有界整数运算，便于跨后端复现。

## 结果的边界

- 暴力扫描与树共享公开几何谓词，主要验证树归属和剪枝；几何正确性另由解析边界用例验证，测试不是形式化证明。
- Double 采用浮点语义，不承诺任意实数上的精确算术。
- 尚未测量构建峰值、稳态字节数、GC 分配、压缩模块大小、首次可查询时间或端到端延迟。
- 尚无 JS/WASM 批量 ABI、浏览器示例、MoonSTRtree/网格对照或移动设备资源验收。
- 尚未发布 Mooncakes 包；动态、单精度和点云功能尚未实施。
