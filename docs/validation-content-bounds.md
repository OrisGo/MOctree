## 取舍

内容边界确实增加了整体命中机会：10 万均匀对象内部子区 count/cap64 约快 10–11 倍，
聚簇局部 count 约快 1.36 倍。但均匀局部 count/cap64 仅改善约 4–8%，
仍慢于本轮 STR；均匀构建稳定慢约 29–32%，1 万均匀对象线性容量从 2,359,296
增至 4,718,592 字节。完整输出和射线还存在不同程度的退化。

因此本表示不足以作为通用默认改进。主要目标中的均匀局部瓶颈仍是父节点跨分割面对象扫描，
不能仅凭内部子区的好结果忽略构建、内存和输出代价。静态查询密集的特定业务可能值得采用，
但本轮没有业务查询/重建频率依据，不能用假定的摊销次数支持默认保留。
后续可单独试验更紧凑的内容边界表示，或父节点候选过滤/输出局部性；均不属于本次已实现功能。

## 实验设计及实现

候选为独立内部 `Node.content_bounds : Aabb`，原 `Node.bounds` 和公开 `NodeInfo.bounds`
始终保持空间单元语义。构建后逆序节点池，合并直属对象与已完成孩子的内容包围盒，
O(N+M) 时间，不重扫每层整棵子树、不增加对象副本或排序数组。父节点编号先于所有后代，
因此逆序汇总成立；子树连续区间和单归属规则保持不变。

只选择输入有限端点的 min/max，无坐标加减或 epsilon；跨分割面对象纳入其所属节点内容边界。
空根复用空间单元边界占位，子树数量为 0。AABB 用内容边界剪枝及整体包含判断，
沿用准确 total_hits、限量写入、恰好填满 Complete 以及实际工作统计。
射线继续使用空间单元边界和原对象谓词；不借本轮引入射线数值语义变化。

选择每节点独立 AABB 是为了复用已验证谓词并隔离实验变量；代价是六个 Double 的坐标载荷
（每非空节点逻辑 48 字节）、Node 引用字段以及 AABB/Vec3 后端表示和分配开销。
自底向上汇总优于每节点重扫子树的 O(N×深度) 方案，但仍不是无成本构建。
没有把内容边界覆盖到公开单元边界，也没有引入动态写入或点云。

[候选源码及专用测试补丁](../benchmarks/content-bounds/experiment.patch)可从最终 checkout 应用；
已在独立临时目录重放并核对测量源码哈希。最终生产 release wasm 与测量 before 模块逐字节一致。
[复现步骤、矩阵和口径](../benchmarks/browser/content-README.md)要求先保存基线模块，再应用补丁。
普通 checkout 不包含内容边界功能。

### 为什么局部查询改善有限

- 均匀局部每批命中 124 个；visited_nodes 仍为 740，tested_objects 19,376 → 19,144，
  只减少约 1.2%。count 仍比本轮 STR 慢约 14–14.7 倍、cap64 约 8.8–11 倍。
  内容边界不能过滤父节点内大量不命中的跨面对象；本轮没有解决这一瓶颈。
- 聚簇局部每批命中 400,000；visited_nodes 2,620 → 1,836，tested_objects
  313,032 → 269,176（减少约 14%）。免测的命中数由 `total_hits-tested_objects`
  的下界从 86,968 增至 130,824；说明整体包含机会增加，但这不是新增公开统计字段。
  count 两轮均减少约 26.6%，cap64 减少约 18–27%，all 只减少约 5%。
  候选 count 仍慢于 STR 约 1.8–2.1 倍，all 约 2.5–2.6 倍。
- 均匀内部子区 visited_nodes 15,283 → 72、tested_objects 88,224 → 13,848，
  命中 101,747 不变；紧边界避免大量空间单元相切造成的无效后代遍历。
  这是真实但特定负载的优势，不能推广为局部查询全面改善。
- 全重叠局部/子区仍测试 800,000 个对象，工作量未减少；延迟波动不能解释成剪枝收益。

### 完整输出退化与小规模结果

全根仍只访问 8 个根、对象测试为 0，但输出仍需间接读取并复制 ID。
10 万均匀全根 all 候选慢约 1.5–10.1%，聚簇全根 all 慢约 3.6–16.6%；
聚簇内部子区 all 两轮都慢约 7–8%。均匀局部 all 也略慢约 0.8–2.2%。
这些组合不因计数快速路径而自动提速。all 预留并传输 8N 个槽位，不能把所有耗时归因于几何遍历。

原始记录包含全部小规模组合。特别是第 2 轮 1 万重叠对象 all：局部 0.715 → 0.950 ms、
子区 0.705 → 0.950 ms、全根 0.335 → 0.485 ms，退化约 33%、35%、45%；
第 1 轮相应为 0.980 → 1.000、0.980 → 1.005、0.495 → 0.475 ms，没有同幅退化。
不把这些未重复的幅度当作稳定结论，也不删掉这些样本；它们说明完整输出尚无稳健改善证据。
