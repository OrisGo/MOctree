# 纯 MoonBit 批量查询验收

日期：2026-10-23。范围：AABB/射线批量查询、区间预校验、逐条状态及根包导出。

本机 Linux，moon/moonrun 0.1.20261020（2284bd2），moonc v0.10.16+b1a0e846e，prek 0.4.14。

- `moon fmt`、`moon info`：完成，已复核生成接口。
- `moon check`：wasm、wasm-gc、js、native 通过。
- `moon test`：wasm、wasm-gc、js 各 27 项通过。
- `MOON_CC=/usr/bin/gcc moon test --target native`：27 项通过。默认编译器包装路径
  `/usr/lib64/ccache/ar` 缺失，显式选择系统 GCC 后完成本次验证。

新增 3 项测试覆盖混合成功/几何失败、报告顺序、独立输出区间、准确总数、恰好填满、
截断、零容量计数、无命中、空索引、空批次、缓冲和工作区复用；验证负偏移、负容量、
越界、整数溢出、乱序/嵌套重叠及工作区不足均在写入前失败。
八种数据分布 × 三档节点预算 × 三档输出容量，每批 24 条 AABB 和 24 条射线，
与暴力扫描比较，并对射线报告与单条查询统计作对照。

本轮不含 JS/WASM 宿主批量协议、浏览器端到端、性能和运行时内存测量。
报告数组及区间排序临时数组会分配内存，未作零分配承诺。M2 尚未整体验收。
