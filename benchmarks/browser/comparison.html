如何解读

MoonSTRtree 三维限量输出先调用完整查询再截取；只计数使用其专用计数接口。MOctree 使用定长缓冲并继续计数。比较的是现有公开 API 的端到端成本，不是纯遍历指令成本。

STR 使用内部序号映射外部 UInt32 ID；没有公开访问计数的字段记为 null。线性内存数值是已分配容量，不是活跃堆或进程峰值。节点预算仅作用于 MOctree，不能据此认为双方内存预算相同。
