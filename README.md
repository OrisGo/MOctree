# MoonBit Octree

面向浏览器等 WASM 运行环境的轻量三维空间索引库，优先保证资源可控、查询正确和批量调用效率。

项目采用“共享几何与基础设施，对象索引与点云索引分别设计，静态与动态类型独立”的路线。首版实现双精度、批量构建、只读查询的 AABB 对象索引；后续扩展单精度存储、动态写入和点云索引。

## 当前状态

截至 2026-10-21，项目处于设计阶段。正式库代码仅有使用 `Double` 的 `Vec3` 及其构造函数，尚未实现八叉树、查询、测试、基准或浏览器适配层。本文描述的是目标，不是已交付能力。

现有 `moon.mod` 的描述仍包含插入、降采样和序列化等早期设想；首版范围以以下文档为准。`moon.pkg` 的后端说明也不代表已经完成多后端验证。本次仅整理文档，未修改代码或模块配置。
